# Timestamply for Cursor

Generate chapter titles and timestamps for a YouTube video in Cursor. Timestamply uses the video's available captions. Review the chapters and paste them into your video description in YouTube Studio.

## Connect Timestamply

1. For a local install, copy this folder to `~/.cursor/plugins/local/timestamply`. The `.cursor-plugin` directory and `mcp.json` should be directly inside it.
2. In Cursor, run **Developer: Reload Window**, then open **Customize → MCP Tools** and connect Timestamply. Sign in to your Timestamply account and approve access in your browser.
3. Open an Agent chat and ask: “Check my remaining Timestamply video allowance.”
4. To generate chapters, ask: “Use Timestamply to generate chapters for this YouTube video: <paste a public YouTube link with captions>.”

Checking your allowance is free. A new generation uses your Timestamply video allowance. Your plan's video length limit applies.
